# 中文学位论文格式规范速查

> 用途：`scripts/format_check.py` 的判定依据；也是人工排版核对时的对照表。
> 默认参数取自《研究生学位论文格式的规定》。**各校细则不同，正式提交前必须以本校研究生院模板为准**——把本校差异写进 `format_check.py` 顶部的 `SPEC` 字典即可。

## 一、页面设置

| 项目 | 规范值 | 脚本判定 |
| --- | --- | --- |
| 纸张 | A4 210×297 mm（docx 11906×16838 twips） | `SPEC.page`，容差 ±40 twips |
| 上边距 | 2.2 cm | `SPEC.margins_cm.top` |
| 下边距 | 2.2 cm | `SPEC.margins_cm.bottom` |
| 左边距 | 2.7 cm | `SPEC.margins_cm.left` |
| 右边距 | 2.2 cm | `SPEC.margins_cm.right` |
| 内容宽度 | 16.1 cm（9128 twips） | 表格列宽之和应等于此值 |
| 印刷 | 前置部分单面，其余双面 | 人工确认 |

## 二、字体字号

| 元素 | 中文字体 | 英文字体 | 字号 | docx `size`（半点） |
| --- | --- | --- | --- | --- |
| 正文 | 宋体 | Cambria Math | 小四 12pt | 24 |
| 章标题 H1 | 黑体加粗 | Cambria Math | 小二 18pt | 36 |
| 节标题 H2 | 黑体加粗 | Cambria Math | 三号 16pt | 32 |
| 条标题 H3 | 黑体 | Cambria Math | 小三 15pt | 30 |
| 款标题 H4 | 宋体 | Cambria Math | 小四 12pt | 24 |
| 图表题注 | 宋体加粗 | Cambria Math | 五号 10.5pt | 21 |
| 页眉页脚 | 宋体 | — | 五号 10.5pt | 21 |
| 目录标题 | 黑体加粗 | — | 三号 16pt | 32 |
| 目录章条目 | 黑体加粗 | — | 四号 14pt | 28 |
| 目录节条目 | 黑体 | — | 小四 12pt | 24 |

递减规则：章 → 节 → 条 → 款，字号逐级下降一档，最低不小四。

**字号对照**（docx 半点值 = pt × 2）：初号 42pt/84，小初 36/72，一号 26/52，小一 24/48，二号 22/44，小二 18/36，三号 16/32，小三 15/30，四号 14/28，小四 12/24，五号 10.5/21。

## 三、页眉页脚

| 规则 | 说明 |
| --- | --- |
| 奇偶页不同 | 奇数页页眉为「硕士学位论文」或「博士学位论文」 |
| 偶数页页眉 | 该页所在章的章标题 |
| 前置部分页码 | 罗马数字 Ⅰ、Ⅱ、Ⅲ（含摘要、目录） |
| 正文页码 | 阿拉伯数字居中，宋体五号 |
| 封面封底 | 不编页码 |

脚本判定：页脚需存在 `PAGE` 域，否则报「页码」提醒。

## 四、排版规则

| 对象 | 规则 | 脚本判定 |
| --- | --- | --- |
| 章标题 | 居中，段前段后 240 twips | 检查 H1 字号/字体 |
| 节标题 | 左起空两格 | 检查 H2 |
| 正文 | 首行缩进 2 字符（小四下 24pt / 480 twips），1.5 倍行距 | 缩进比例 <85% 报提醒，<50% 报严格 |
| 图题 | 图**下方**居中，「图3-1」，分图用 (a)(b)(c) | 识别题注并检查是否带缩进 |
| 表题 | 表**上方**居中，「表3.1」 | 同上 |
| 表格 | 三线表：顶/底 1.5pt（sz=12），栏目线 0.75pt（sz=6），无竖线 | `--fix-tables` 可自动处理 |
| 公式 | 行首算起第 5 个中文字符处起始，编号右对齐 (章.序) | 人工确认 |
| 引用 | 正文上标方括号 [1]，按出现次序编号 | 检查是否存在 [n] |

## 五、序号体例

| 层级 | 格式 | 示例 |

| 章 | 第X章 | 第一章、第二章 |
| 节 | 第X节 | 第一节、第二节 |
| 条 | X、 | 一、二、三 |
| 款 | （X） | （一）（二） |
| 项 | X | 1、2、3 |
| 子项 | （X） | （1）（2） |

图表公式附注用阿拉伯数字分章编号：图1-2、表2.3、式(6.3)、文献[4]。

理工科常用阿拉伯章节号（1、1.1、1.1.1），脚本对两种体例都接受，只检查标题样式是否成套。

## 七、结构完整性清单

```text
封面 → 扉页（英文封面） → 独创性声明 → 中文摘要（约800字，关键词3-5个）
→ 英文摘要（500-800词，Keywords） → 目录（论文目录 + 图目录 + 表目录）
→ 符号/缩略词说明（必要时） → 绪论 → 文献综述 → 正文各章 → 结论
→ 致谢/后记 → 参考文献 → 附录（A/B/C） → 封底
```

摘要要求：中文用第三人称；英文避免「This paper」作主语，多用被动；关键词用公知公用词。

## 八、修改本校参数

打开 `scripts/format_check.py`，改顶部 `SPEC` 字典即可，无需改判定逻辑：

```python
SPEC = {
    "page": {"width_twips": 11906, "height_twips": 16838, "tolerance_twips": 40},
    "margins_cm": {"top": 2.5, "bottom": 2.5, "left": 3.0, "right": 2.5, "tolerance_cm": 0.15},
    "body": {"east_asia": "宋体", "latin": "Times New Roman", "size_pt": 12, "line_multiple": 1.5},
    "headings": {1: {"east_asia": "黑体", "size_pt": 16, "bold": True, "align": "center"}, ...},
    ...
}
```

常见差异项：边距（2.5/2.5/3.0/2.5 很常见）、正文字号（五号 10.5pt）、行距（固定 20pt）、章标题字号（三号）。改完先跑一遍 `--out` 只体检不修改，确认判定符合本校要求后再用 `--fix`。

## 九、与 docx-js 生成流程的衔接

若论文是由 `docx` 库脚本生成的（而非 Word 手工排版），以下约束必须遵守，否则脚本无法识别或 Word 打开报错：

- A4 页边距用 DXA：`top: 1247, bottom: 1247, left: 1531, right: 1247`
- 不用 `\n` 换行，用独立 `Paragraph`
- `PageBreak` 必须放在 `Paragraph` 内
- 表格宽度用 DXA，`columnWidths` 之和 = 内容宽度 9128
- `font` 必须是对象 `{ ascii, eastAsia, hAnsi }`，不能传字符串
- 标题样式必须带 `outlineLevel`（H1=0，H2=1，H3=2，H4=3），否则无法生成目录
- 覆盖样式用精确名称 `Heading1`…`Heading4`（style_id），显示名为 `Heading 1`…`Heading 4`
