# 中文学术 AI 高频词黑名单

> 用途：`scripts/ai_scan.py` 直接解析本文件的表格（`| 词 | 级别 | 替换方向 |`）作为扫描词库；改写时按级别决定处理力度。
> 维护方式：只增不删；新增词必须给出级别和替换方向，不要只列词。

## 分级口径

| 级别 | 含义 | 处理力度 |
| --- | --- | --- |
| T1 | 强标记：出现即在绝大多数语境下可判为套话，学术文本中几乎不承担信息量 | 直接删除或改为事实陈述，一轮必清 |
| T2 | 中标记：本身合法，但密集出现即暴露模板化行文 | 保留语义、换更朴素的说法，同段不超过 1 次 |
| T3 | 弱标记：书面语正常用法，仅作为统计信号 | 不计入硬性改写，仅在密度过高时抽查 |

> T1 目标：全文 0 处。T2 目标：每千字 ≤ 3 处。T3 目标：不设硬指标，看密度趋势。

## 不进入黑名单的词

以下词汇虽然常被误判为「AI 味」，但在计算机学位论文中属于必要术语，**不得替换**：

- 模型、模块、机制、架构、框架、范式、基线、消融、收敛、泛化、鲁棒性
- 端到端、自注意力、残差、批归一化、蒸馏、微调、推理、训练、验证集
- 显著性、置信区间、方差、均值、标准差、复杂度、吞吐量、时延
- 本文、本系统、本研究、我们（作为作者视角合法使用）

> 判断口径：术语承担了指代具体技术实体的功能，替换会破坏可复现性；套话只承担语气功能，删掉不影响信息。

## 使用方式

```bash
# 扫描并输出风险报告（词库自动从本文件读取）
python scripts/ai_scan.py --docx paper.docx --out out/

# 指定其他词库
python scripts/ai_scan.py --docx paper.docx --out out/ --lexicon my_lexicon.md
```

改写时按 T1 → T2 顺序处理，T3 只看密度。改写完成后再扫一次，T1 应为 0，变异系数应上升。
